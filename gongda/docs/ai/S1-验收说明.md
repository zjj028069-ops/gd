# S1 厂长助理（盯三本账）· 验收说明

> 基线：`release/sedric-v1.0.23`（`22e80ae…`）现网毛玻璃侧栏 + chat-shell  
> 叠层：S0 `ai-s0-trust-base`（v1.0.24）之上  
> 本功能版本：**SEDRIC01 v1.0.25** · feature `ai-s1-factory-ask`  
> 规格：`AI四能力-交互规格-2026-10-20.md`

## 范围

1. **自然语言问三本账**（只读）：进度 / 应收欠款 / 工资待审及同义说法 → `POST /api/ai/factory/ask`  
2. **结构化卡片**：标题 + 关键数字/列表摘要；不是纯文本一句糊弄  
3. **「去处理」深链**：打开真实 MES 模块（进度→加工单列表；钱→客户往来/收支；工资→报工记录），只导航不写库  
4. **手动「查一下三本账」**：一次返回三组只读摘要（`intent=triple` + `books[]`）；聊天工具栏「三本账」按钮或固定话术  
5. **晨报/异常推送**：预留 `GET /api/ai/factory/briefing`、`POST /api/ai/factory/briefing/subscribe`（stub，本冲刺不推送）

## 非目标

写库、真正推送、OCR 落单、本厂词典产品化（属后续冲刺）。

## 意图 → 深链

| 意图 | 示例问法 | `action_path` |
|------|----------|----------------|
| progress | 进度怎么样、今天生产进度怎么样 | `/inside_produce_bill/list` |
| money | 应收还有多少、还欠多少钱 | `/customer_financier/list` |
| wage | 工资待审、工资有没有待审 | `/work_repoty_record/list` |
| triple | 查一下三本账、三本账 | 每本账各自 `action_path` |

操作指引 FAQ（「怎么报工」等）仍走知识库/开放路径，**不**误进三本账查数。

## 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/ai/factory/ask` | 厂长助理只读；单意图带 `action_path`；三本账带 `books[]` |
| GET | `/api/ai/factory/briefing` | 晨报/推送能力元信息（stub） |
| POST | `/api/ai/factory/briefing/subscribe` | 订阅意向记录（stub，不发送） |

## 验收清单

1. 聊天问「应收还有多少」→ 厂长助理只读卡片（有数字或明确空态），不是 FAQ 流程图  
2. 「进度怎么样」「工资待审」同理；「查一下三本账」一次出三卡  
3. 「去处理」打开对应 MES 路由（iframe URL 或可见模块标题正确）  
4. 单测：意图 → factory/ask；冒烟：`scripts/ai-s1-smoke.mjs`  
5. 截图至少 2 张：三本账卡片、点「去处理」后的 MES 页（仍是毛玻璃侧栏壳）  
6. **禁止**：重建库、改开发账号密码、改 garment-*、伪造截图、回退到 main/旧 rail 壳
