# S0 可信执行底座 · 验收说明

> 基线：`release/sedric-v1.0.23`（HEAD `22e80ae…`，SEDRIC01 v1.0.23 现网毛玻璃侧栏）  
> 本功能版本：**SEDRIC01 v1.0.24** · feature `ai-s0-trust-base`  
> 规格：`AI四能力-交互规格-2026-10-20.md`

## 范围

1. **统一写库**：`preview → POST /api/ai/writes/confirm|cancel`；确认前不写；失败也记审计  
2. **审计表** `ai_action_audit` + 可读接口 `GET /api/ai/writes/audit`  
3. **附件认型骨架**：`order_doc | business_card | other | unknown`；名片 → 客户/供应商联系人确认卡，**不**落合同/加工单  
4. **S1 挂钩**：聊天问「进度 / 钱 / 工资」→ `POST /api/ai/factory/ask`（只读）  
5. **文档**入 `docs/ai/`；Playwright 冒烟 `scripts/ai-s0-smoke.mjs`

## 非目标

完整 OCR、晨报、扩展应用、本厂词典产品化；真单据打穿属 S2。

## 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/ai/writes/confirm` | 统一确认写库（`kind`: bom / quick_order / drawing / contact） |
| POST | `/api/ai/writes/cancel` | 统一取消预览，不写业务表 |
| GET | `/api/ai/writes/audit?preview_id=&limit=` | 可读审计列表 |
| POST | `/api/ai/intake/classify` | 附件认型（multipart：`file` + 可选 `note` / `force_kind`） |
| POST | `/api/ai/factory/ask` | 工厂助理只读（S1 聊天入口复用） |

兼容：原 `/api/ai/{bom,quick-order,drawing}/confirm|cancel` 仍保留；MES AI 页已切到统一 writes。

## 迁移与回滚

- 正向：`apps/api/migrations/118_ai_s0_trust_base.sql`（`ai_action_audit`）  
- 回滚：手动执行 `apps/api/migrations/down/118_ai_s0_trust_base.down.sql`，再  
  `DELETE FROM schema_migrations WHERE name = '118_ai_s0_trust_base.sql';`  
- **不重建库**；不改开发账号密码；不触 `garment-*`；主色 `#4184F4`

## 验收清单

1. 极速下单 / BOM / 图纸拆单：确认前不写库；经 `/api/ai/writes/confirm` 后 `ai_action_audit.result='ok'`  
2. 聊天或 API 扔名片（或模拟文本）：`kind=business_card` 出确认卡；确认只写 `money_contacts`（或供应商联系字段），**不**创建 `money_contracts` / `work_orders`  
3. 聊天问「应收还有多少」：调工厂助理只读回答  
4. 冒烟截图可见 **现网毛玻璃侧栏**（`.kgd-sidebar-primary`，工作台/生产管理等）；若见旧 `.kgd-rail` 主导航 → **基线错误，停交**
