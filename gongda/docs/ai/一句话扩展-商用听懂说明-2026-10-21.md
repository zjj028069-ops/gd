# 一句话生成新功能 · 商用听懂（v1.0.33）

## 纠正

3 个合格样例是**验收夹具**，不是话术白名单。商用能力必须是：

任意人话 → 结构化方案（LLM）→ 白名单实体/动作校验 → 确认卡 → 写库 → 打开入口+指引。

规则引擎只做：**控制指令、无 Key 兜底、LLM 失败回落**。

## 现网路径

1. `chat-shell` 宽意图 `looksLikeS3`（不绑死样例句）
2. `resolveExtUtterance`：有 `AI_API_KEY` 时 LLM 出 JSON；否则/失败走开放字段名规则
3. 预览卡 → 确认 → 执行器（单据 `entity_ext` / 商品 `extension_schemas` 发布 / 轻量应用）
4. 回执：打开单据入口 + 指引；可「回退该扩展」

## 配置

- `AI_PROVIDER=openai`
- `AI_API_KEY=...`
- 可选：`AI_OPENAI_BASE`、`AI_OPENAI_MODEL`（默认 gpt-4o-mini）

无 Key 时仍可用规则听懂开放字段名，但口语覆盖面与歧义处理弱于 LLM。
