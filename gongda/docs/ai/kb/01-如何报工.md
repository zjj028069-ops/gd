# 如何报工

## 入口
- 菜单：生产管理 → 报工工作台（`/work_report_workbench`）
- 或：生产管理 → 生产任务 → 行上「详情」打开报工弹窗
- 手机端：扫码或打开移动报工 `/m/report`

## 步骤
1. 选择加工单与工序（或扫任务二维码）。
2. 填写生产人员、良品数、不良品数；需要时填机台、时长、备注。
3. 点击「报工」提交；若工序已完成可选「报工并完成工序」。
4. 提交后可在「报工记录」查看；若开启审核，需质检/审核通过后才计入工资。

## 注意
- 报工数量一般不超过任务计划数（企业可配置）。
- 本助手只说明操作步骤，不会替您提交报工单据。
