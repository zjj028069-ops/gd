## 3. 根因核实

| 现象 | 核实 |
|------|------|
| 计划数 10 → 分析后 0.00001 | `apps/api/src/material-analysis.ts` 以 JS `Number` 做人读运算后，写入时用 `formatDecimal(BigInt(Math.round(n)))`。`formatDecimal` 约定入参为微单位 bigint（`SCALE=1e6`），裸 `10` 被格式化成 `0.000010`。 |
| 0.00003 / 0.00001 | 同上错误缩放；采购对应外购件「梭织面料」。 |
| 商品BOM「无」 | `progress.ts` 详情组装硬编码 `bom_label: '无'`；创建/更新 `product_snapshot` 未写入 BOM。 |

## 4. 改动文件

| 路径 | 改动 |
|------|------|
| `apps/api/src/material-analysis.ts` | 新增 `storeHumanQty`：`formatDecimal(BigInt(Math.round(n * Number(SCALE))))`；分析汇总与 analysis_lines 写入改走该函数 |
| `apps/api/src/progress.ts` | `defaultBomForProduct` / `bomLabelOf`；创建与 PATCH 写入 snapshot.`bom_id`/`bom_code`/`bom_label`；详情优先读 snapshot，否则回落查默认 BOM |
