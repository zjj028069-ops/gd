# 手机版（扫码报工 · 加工单）

手机打开系统任意网址会自动进入手机版（`/m`），界面和电脑版同一套毛玻璃风格，换「外观」配色手机版也跟着变。
手机上点「我的 → 切换到电脑版」可以用电脑版，电脑版右下角有「手机版」按钮可以切回来。

## 扫码
- 加工单详情里的「加工单二维码」现在是网址：`<手机访问地址>/m/wo/<加工单号>?t=<企业标识>`。
- 工人用手机相机扫码 → 打开登录页（企业标识已自动填好，以后也会记住）→ 登录后直接进到这张加工单。
- 任务列表里的「查看二维码」、顶栏「下载APP」的二维码也都换成了手机能打开的地址。

## 能做什么
| 谁 | 能做 |
|---|---|
| 工人（只勾「生产管理 → 报工」） | 看加工单、给分配给自己的工序报工（良品/不良/不良品项/机台/时间/备注，实时算工资）、看今日报工 |
| 有「生产管理」权限的人 | 以上全部，可以给任何工序报工并**替工人代报**（选生产人员，报工记在工人名下；同一项权限也包括审核/撤销报工、超计划补产），加上：加工单列表（状态筛选、搜索）、详情（工序进度、用料、最近报工）、开工 / 暂停（填原因）/ 继续 / 完工 / 取消（必须填原因）、新建加工单（选商品、数量、工艺路线或自选工序、交货日期、优先级） |

权限和电脑版完全一样（同一套接口和登录），手机上看不到的按钮，接口也会拒绝。

## 新增的「报工」权限
「系统管理 → 角色管理 / 用户管理」的权限里，生产管理下多了一个「报工」。只勾它的人能报工，但不能开工、取消、新建加工单，适合给工人。
（以前有个 bug：在用户管理里建的账号，即使给了生产管理权限也报不了工，已修好。）
报工前还要在「工序管理 → 修改 → 生产人员」里把工人加到对应工序。

## 手机怎么连上
- 手机和电脑连**同一个 WiFi**。启动时命令行窗口会打印「手机访问地址」（本机现在是 `http://192.168.0.8:5173`）。
- 启动脚本会自动找本机局域网地址，写进二维码，并只放行这个地址（别的来源仍然拒绝）。
- 部署到服务器时设置环境变量 `MOBILE_BASE_URL=https://你的域名`（二维码用），`EXTRA_ORIGINS` 可以再放行其他 https 地址。

## 代码
- 界面：`apps/web/src/kgd/pages/mobile/`（`MobileApp.tsx`、`MobileLogin.tsx`、`device.ts`、`mobile.css`）
- 设置：`apps/api/src/config.ts`（`EXTRA_ORIGINS`、`MOBILE_BASE_URL`），接口 `GET /api/mobile/config`
- 权限：`apps/api/src/kgd-permissions.ts`（`produce.report`）

每道工序都有「报工」按钮：能报的直接进报工页；不能报的点了会说明原因（不在生产人员名单、加工单没开工/已暂停、没有报工权限）和怎么开通。
