目标：创建工艺路线 — 前置步骤

从上到下：先完成必做，建议项可按场景跳过；最后一步用于验证路线可用。

目标
创建工艺路线
把已有工序排成固定顺序，开加工单时可一次带入。
生产管理 → 工艺路线 → 新增
① 必做
录入至少一道工序
路线只能从「工序池」选节点；没有工序就组不成路线。
生产管理 → 工序管理 → 新增（工序名 / 计价方式 / 工资单价）
② 建议
工序勾选生产人员
后面报工、问工资要落到人；建路线不强制，缺了报工易卡住。
工序管理 → 编辑 → 生产信息 → 生产人员
③ 建议
若路线挂商品/BOM，先建商品
只建公共路线可跳过；要挂商品时再做。
商品管理 → 商品列表 → 新增
④ 必做
新增工艺路线并保存
起路线名，按顺序加入已有工序，保存。
生产管理 → 工艺路线 → 新增 → 选工序排序 → 保存
⑤ 验证
加工单里「从工艺路线中添加」
能一次带入整串工序，即目标达成。
生产管理 → 加工单 → 从工艺路线中添加
目标 必做 建议 验证
