## 专题节点摘要（逐项打勾）

### `login` — 怎么登录

- [ ] 问法命中后出现流程图
- summary：用管理员给你的网址、账号和密码进入系统，登录成功后直接到「工作台」。
- hint：从上到下：先拿到入口与账号，再完成登录；最后确认落到工作台。

| 序 | 类型 | 标题 | 路径 |
|----|------|------|------|
| 1 | 目标 | 登录进入工作台 | 浏览器 → 登录页 → 确定 |
| 2 | 必做 | 拿到系统网址与账号密码 | 找企业管理员要网址 / 账号 / 初始密码 |
| 3 | 建议 | 使用常用浏览器，关大小写锁定 | Chrome / Edge 等 |
| 4 | 必做 | 打开网址并填写账号密码 | 登录页 → 确 定 |
| 5 | 验证 | 进入工作台 | 工作台；头像 → 退出登录 |

### `ui-layout` — 认识界面（四大区）

- [ ] 问法命中后出现流程图
- summary：屏幕分成四块：左边一级菜单、二级菜单、顶部工具条、中间工作区。认清以后每章说「点哪里」都能找到。
- hint：从上到下：先认出四大区，再在工作区完成业务；用面包屑确认当前位置。

| 序 | 类型 | 标题 | 路径 |
|----|------|------|------|
| 1 | 目标 | 认识界面四大区 | 任意已登录页面 |
| 2 | 必做 | 先登录进系统 | 登录页 → 工作台 |
| 3 | 必做 | 认一级菜单与二级菜单 | 左侧一级 → 二级菜单 |
| 4 | 建议 | 看顶部面包屑与头像区 | 顶部工具条 |
| 5 | 验证 | 在工作区打开任一列表 | 中间工作区 |

### `list-page` — 列表页怎么用

- [ ] 问法命中后出现流程图
- summary：学会一个列表页，其它菜单都会了：快捷筛选 → 查询 → 红字汇总 → 按钮行 → 表格。
- hint：从上到下：先进任意列表，再学筛选查询与批量；用红字汇总与列配置自检。

| 序 | 类型 | 标题 | 路径 |
|----|------|------|------|
| 1 | 目标 | 会用任意列表页 | 任意业务列表（如加工单/合同） |
| 2 | 必做 | 先认识界面并打开一个列表 | 左侧菜单 → 列表 |
| 3 | 必做 | 会用筛选与查询 | 列表顶部筛选 / 查询区 |
| 4 | 建议 | 看红字汇总与列配置 | 列表上方汇总；右侧列配置 |
| 5 | 验证 | 勾选后批量操作可点 | 表格勾选 → 批量操作 |

### `onboard` — 开户准备（企业/用户/角色）

- [ ] 问法命中后出现流程图
- summary：第一次用先配企业信息、角色权限、用户账号。菜单：系统管理 → 企业信息设置 / 用户管理 / 角色管理。
- hint：从上到下：先配企业与角色，再建用户；勿点清空数据。

| 序 | 类型 | 标题 | 路径 |
|----|------|------|------|
| 1 | 目标 | 开户准备就绪 | 系统管理 → 企业 / 角色 / 用户 |
| 2 | 必做 | 用管理员账号登录 | 登录 → 系统管理 |
| 3 | 必做 | 填企业信息并保存 | 系统设置 → 企业信息设置 → 保存 |
| 4 | 必做 | 建角色并勾权限 | 角色管理 → 新增 → 提交 |
| 5 | 必做 | 新增用户并选角色 | 用户管理 → 新增 → 提交 |
| 6 | 建议 | 千万别点「清空系统数据」 | 系统管理（避开危险按钮） |
| 7 | 验证 | 新用户能登录且菜单正确 | 退出 → 新账号登录 |

### `goods-create` — 怎么新增商品

- [ ] 问法命中后出现流程图
- summary：口语常说「产品」，系统里叫「商品」。路径：商品管理 → 商品列表 →「+ 新增」。至少填「商品名」。
- hint：从上到下：先进商品列表，至少填商品名保存；列表出现绿名即成功。

| 序 | 类型 | 标题 | 路径 |
|----|------|------|------|
| 1 | 目标 | 新增商品 | 商品管理 → 商品列表 → + 新增 |
| 2 | 必做 | 有权限进入商品管理 | 商品管理 → 商品列表 |
| 3 | 建议 | 需要分类时先建类别/单位 | 商品管理 → 类别 / 单位（可选） |
| 4 | 必做 | 新增并填「商品名」 | + 新增 → * 商品名 → 确定 |
| 5 | 建议 | 补类别、单位、商品来源 | 新增商品窗口其它字段 |
| 6 | 验证 | 列表出现绿色商品名 | 商品列表 |

### `craft-process` — 怎么录入工艺（工序）

- [ ] 问法命中后出现流程图
- summary：要算工资，先建「工序」并定工资单价与生产人员。路径：生产管理 → 工序管理 →「新增」。
- hint：从上到下：先建工序并定计价/单价，建议勾生产人员；列表出现即成功。

| 序 | 类型 | 标题 | 路径 |
|----|------|------|------|
| 1 | 目标 | 录入工序 | 生产管理 → 工序管理 → 新增 |
| 2 | 必做 | 进入工序管理 | 生产管理 → 工序管理 |
| 3 | 必做 | 填工序名、计价方式、工资单价 | 新增 → 工序名 / 计价方式 / 工资单价 |
| 4 | 建议 | 生产信息里勾选生产人员 | 生产信息 → 生产人员 |
| 5 | 验证 | 工序列表出现该行 | 工序管理列表 |

### `craft-route` — 怎么建工艺路线

- [ ] 问法命中后出现流程图
- summary：把已有工序排成固定顺序，开加工单时可一次带入。先完成必做，建议项可按场景跳过；最后用加工单验证。
- hint：从上到下：先完成必做，建议项可按场景跳过；最后一步用于验证路线可用。

| 序 | 类型 | 标题 | 路径 |
|----|------|------|------|
| 1 | 目标 | 创建工艺路线 | 生产管理 → 工艺路线 → 新增 |
| 2 | 必做 | 录入至少一道工序 | 生产管理 → 工序管理 → 新增（工序名 / 计价方式 / 工资单价） |
| 3 | 建议 | 工序勾选生产人员 | 工序管理 → 编辑 → 生产信息 → 生产人员 |
| 4 | 建议 | 若路线挂商品/BOM，先建商品 | 商品管理 → 商品列表 → 新增 |
| 5 | 必做 | 新增工艺路线并保存 | 生产管理 → 工艺路线 → 新增 → 选工序排序 → 保存 |
| 6 | 验证 | 加工单里「从工艺路线中添加」 | 生产管理 → 加工单 → 从工艺路线中添加 |

### `contract` — 客户与合同订单

- [ ] 问法命中后出现流程图
- summary：先录客户，再开合同/订单。路径：客户管理 → 客户管理 / 合同订单。
- hint：从上到下：先有客户，再开合同；建议商品已建。用欠款/审核验证。

| 序 | 类型 | 标题 | 路径 |
|----|------|------|------|
| 1 | 目标 | 客户与合同订单 | 客户管理 → 客户 / 合同订单 |
| 2 | 必做 | 新增客户 | 客户管理 → 新增 → 确定 |
| 3 | 建议 | 先建好要卖的商品 | 商品管理 → 商品列表 → 新增 |
| 4 | 必做 | 新增合同并加明细 | 合同订单 → + 新增 |
| 5 | 建议 | 需要时走批量审核 | 合同列表 → 批量操作 |
| 6 | 验证 | 列表有合同且可见欠款 | 合同订单列表 |

### `purchase` — 采购与供应商

- [ ] 问法命中后出现流程图
- summary：先录供应商，再做采购计划/采购单。路径：供应/采购 → 供应商管理 / 采购。
- hint：从上到下：先有供应商与外购商品，再开采购单；用欠款/付款验证。

| 序 | 类型 | 标题 | 路径 |
|----|------|------|------|
| 1 | 目标 | 采购与供应商 | 供应/采购 → 供应商 / 采购单 |
| 2 | 必做 | 新增供应商 | 供应商管理 → 新增 → 确定 |
| 3 | 建议 | 商品来源标为外购 | 商品管理 → 新增（外购） |
| 4 | 必做 | 新增采购单 | 采购 ▾ → 采购单 → + 新增 |
| 5 | 验证 | 列表有单且可见欠款/付款 | 采购单列表 |

### `warehouse` — 仓库出入库与库存

- [ ] 问法命中后出现流程图
- summary：采购到货做入库，发货做出库；随时在「库存管理」看结存。
- hint：从上到下：入库依赖采购/到货，出库依赖合同发货；用库存管理核对结存。

| 序 | 类型 | 标题 | 路径 |
|----|------|------|------|
| 1 | 目标 | 出入库与库存正确 | 仓库管理 → 入库 / 出库 / 库存 |
| 2 | 必做 | 有可入库来源 | 采购单「入库」或 采购入库单 → 新增 |
| 3 | 建议 | 出库前合同/销售已就绪 | 合同订单「出库」 / 销售出库单 |
| 4 | 必做 | 完成入库或出库单据 | 对应入库单 / 出库单 |
| 5 | 验证 | 库存管理结存变化 | 仓库管理 → 库存管理 / 出入库流水 |

### `work-order` — 怎么开加工单

- [ ] 问法命中后出现流程图
- summary：生产管理 →「加工单」→「+ 新增」。可直接创建，也可从合同创建。开单前商品、工序要先建好。
- hint：从上到下：开单前商品与工序（或路线）要先有；保存后能从列表进详情。

| 序 | 类型 | 标题 | 路径 |
|----|------|------|------|
| 1 | 目标 | 开加工单 | 生产管理 → 加工单 → + 新增 |
| 2 | 必做 | 先建商品 | 商品管理 → 商品列表 → 新增 |
| 3 | 必做 | 先有工序（或工艺路线） | 工序管理 / 工艺路线 |
| 4 | 建议 | 从合同创建时先有合同 | 客户管理 → 合同订单 |
| 5 | 必做 | 新增加工单并保存 | 加工单 → + 新增 → 保存 |
| 6 | 验证 | 列表有单号，可进详情 | 加工单列表 → 详情 |

### `report-work` — 怎么报工

- [ ] 问法命中后出现流程图
- summary：工人每天要做的事。可在加工单详情点「报工」，或走报工工作台/生产任务。
- hint：从上到下：先有加工单与工序人员，再报工；报工记录能查到即成功。

| 序 | 类型 | 标题 | 路径 |
|----|------|------|------|
| 1 | 目标 | 报工 | 加工单详情 → 报工 |
| 2 | 必做 | 已有加工单且含工序 | 生产管理 → 加工单 |
| 3 | 必做 | 工序已配置可报人员 | 工序管理 → 生产信息 → 生产人员 |
| 4 | 建议 | 加工单已开始相应工序 | 加工单详情 → 开始工序 |
| 5 | 必做 | 填报工并确定 | 报工弹窗 → 确定 |
| 6 | 验证 | 报工记录可查 | 生产管理 → 报工记录 |

### `wage` — 问工资

- [ ] 问法命中后出现流程图
- summary：工资来自报工：单价 × 良品数。看明细用「报工记录」，汇总用「生产工资报表」。
- hint：从上到下：工资来自已报工；先查报工记录再结算/看报表。

| 序 | 类型 | 标题 | 路径 |
|----|------|------|------|
| 1 | 目标 | 问工资 / 结算 | 报工记录 / 生产工资报表 |
| 2 | 必做 | 已有报工记录 | 加工单报工 → 报工记录 |
| 3 | 必做 | 工序工资单价已维护 | 工序管理 → 工资单价 |
| 4 | 建议 | 先筛未结算再批量结算 | 报工记录 → 结算 / 批量操作 |
| 5 | 验证 | 报表能按人汇总 | 生产工资报表 |

### `money` — 问钱（欠款/收款）

- [ ] 问法命中后出现流程图
- summary：合同订单上方红字【欠款】= 客户还欠多少。收款走合同「收款」或「收支记录」。
- hint：从上到下：先有合同/采购产生欠款，再收款或付款；用收支记录核对。

| 序 | 类型 | 标题 | 路径 |
|----|------|------|------|
| 1 | 目标 | 问钱（欠款/收款） | 合同订单 / 收支记录 / 采购单 |
| 2 | 必做 | 已有合同或采购单 | 合同订单 或 采购单 |
| 3 | 必做 | 在合同上收款（客户侧） | 合同订单 → 收款 |
| 4 | 建议 | 供应商侧走采购付款 | 采购单 → 付款 |
| 5 | 验证 | 欠款减少且收支有流水 | 收支记录 / 发票管理 |

### `progress` — 问进度

- [ ] 问法命中后出现流程图
- summary：看一张单做到哪：加工单详情/进度；看全厂：生产任务、生产排产、产量报表、数据大屏。
- hint：从上到下：单笔看加工单详情，全厂看任务/排产；老板用待办+报表收口。

| 序 | 类型 | 标题 | 路径 |
|----|------|------|------|
| 1 | 目标 | 问进度 | 加工单详情 / 生产任务 / 排产 |
| 2 | 必做 | 已有加工单在流转 | 生产管理 → 加工单 |
| 3 | 必做 | 打开单号看工序完成情况 | 加工单 → 详情 |
| 4 | 建议 | 全厂用生产任务与排产 | 生产任务 / 生产排产 |
| 5 | 验证 | 待办与报表能对上现场 | 工作台 / 报表中心 |

### `roles-daily` — 分角色每天做什么

- [ ] 问法命中后出现流程图
- summary：按岗位找自己每天要盯的菜单。老板优先：进度、钱、工资三件事。
- hint：从上到下：先明确自己角色，再按岗位盯对应菜单；老板优先进度、钱、工资。

| 序 | 类型 | 标题 | 路径 |
|----|------|------|------|
| 1 | 目标 | 按角色完成每日工作 | 工作台 + 各业务菜单 |
| 2 | 必做 | 账号角色权限正确 | 系统管理 → 用户 / 角色 |
| 3 | 必做 | 老板：待办 → 欠款 → 进度 → 工资 | 工作台 / 合同 / 加工单 / 报工记录 |
| 4 | 建议 | 文员跟单 / 仓管 / 车间 / 财务分线 | 对应模块菜单 |
| 5 | 验证 | 当日待办能清或有下文 | 工作台待办 |

### `faq` — 常见问题 FAQ
